Student Management System

A Python-based Student Management System designed to simplify the management of student records and academic information.

📌 Overview

The Student Management System is a console-based Python application that allows users to manage student information in an organized manner.

The project was developed as a practical application of Python programming concepts, including object-oriented programming, modular design, file handling, validation, and data management.

✨ Features

- Add new student records
- View student information
- Manage existing student records
- Organize students according to their academic information
- Validate user input
- Store and retrieve student data
- Modular and organized project structure

🛠️ Technologies Used

- Python 3
- Object-Oriented Programming (OOP)
- File Handling
- Data Validation
- Modular Programming

🚀 Getting Started

Prerequisites

Make sure Python 3 is installed on your computer.

You can verify your Python installation with:

python --version

Installation

Clone the repository:

git clone https://github.com/Clement-A2/Student-Management-System.git

Navigate into the project directory:

cd Student-Management-System

Running the Application

Run the main program:

python main.py
